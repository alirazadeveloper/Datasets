# Cross-Species DNA and RNA Methylation Sequence Dataset

## Overview

This repository contains a cross-species nucleotide sequence dataset covering four major types of epigenetic modifications: **4-methylcytosine (4mC), 5-methylcytosine (5mC), N6-methyladenine (6mA), and N6-methyladenosine (m6A)**.

## Dataset Characteristics

The dataset is designed for cross-species methylation sequence analysis and computational prediction.

Key characteristics include:

- **Cross-species coverage:** Nucleotide sequences collected from multiple organisms.
- **Four methylation types:** 4mC, 5mC, 6mA, and m6A.
- **Sequence-based representation:** Methylation-associated nucleotide sequences.
